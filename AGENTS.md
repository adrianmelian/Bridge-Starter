# Bridge starter workspace
Read context/data.md, context/identity.md, context/preferences.md and context/goals.md.
This is a fresh workspace. Ask the owner about their first project and preferences.
Keep project context under projects/, decisions under knowledge/, and workflows
under processes/. Register report cards in workspace/workspace.json when created.
Use the owner's chosen agent, model and permissions. Never copy account credentials
into this repository. Keep runtime state, transcripts, .env and receipts out of Git.
Ask before restarting an app, publishing content or making paid calls. Configure
only the accounts and integrations the owner requests. Do not claim tools are
connected merely because they are mentioned in documentation. Explain decisions
in the chat; do not depend on popup questionnaires.
Git is optional for the recipient; obtain their repository and publishing choices.
